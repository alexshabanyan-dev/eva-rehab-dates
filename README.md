# Eva Rehab — Даты

Vue 3 + TypeScript приложение для выбора дат в Telegram Mini App.

## Стек

- **Vue 3** + **TypeScript** + **Vite**
- **V-Calendar** — календарь с прокруткой месяцев
- **vue-tg** — интеграция с Telegram Mini App SDK

## Особенности

- Календарь с прокруткой: отображаются месяцы начиная с текущего (24 месяца вперёд)
- Адаптация под тему Telegram (светлая/тёмная)
- При клике на дату — отправка в бота через `sendData` (при запуске из Telegram)
- Вне Telegram — показ выбранной даты через `alert` (удобно для разработки)

## Разработка

```bash
npm run dev
```

Открой в браузере — появится **панель симуляции Telegram** с переключателем светлой/тёмной темы, чтобы видеть, как приложение будет выглядеть в Telegram.

Параметры URL:
- `?theme=light` — светлая тема
- `?theme=dark` — тёмная тема
- `?width=375` — ширина viewport в пикселях (320–600)

## Сборка

```bash
npm run build
```

Результат в папке `dist/`. Выложи на хостинг и укажи URL в настройках Mini App бота.

## Подключение к боту

В боте настрой Web App кнопку. При выборе даты пользователем приложение отправит JSON:
```json
{"date": "2025-02-15T00:00:00.000Z"}
```

Обработай это в обработчике `web_app_data` в своём боте.
